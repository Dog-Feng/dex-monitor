1. 当前看板结论怎么来的

上方「结论」列由规则引擎生成。核心是 15 分钟涨跌 + 30 分钟 OI 变化 + 资金费率；OI÷市值用来判断杠杆是否过热。大户多空比目前只展示，不单独触发结论，用来辅助确认拥挤方向。

根据什么 得到什么结论
价涨 + OI 下降 + 费率 ≤ 0 空头被平或爆仓，持仓在降 → 轧空 / 逼空（short_squeeze）
价涨 + OI 上升 + 费率 > 0 有人在加多、费率变贵 → 主动拉盘追多（long_chase）
价涨 + 费率极负（如 ≤ -0.5%） 空头极度拥挤、空头在给多头付费 → 高位轧空末段，也警惕反转
价跌 + OI 下降 + 费率 > 0 多头被打掉、持仓在降 → 多头清算 / 清多（long_liquidation）
价跌 + OI 上升 + 费率 < 0 下跌时还有人在加空 → 加空砸盘（short_build）
OI÷市值 ≥ 0.2 合约名义持仓相对流通盘过大 → 杠杆过热，波动容易被放大
OI÷市值 ≥ 0.3，或费率极端 在暴涨/暴跌之上再升一档 → 严重程度 HIGH，优先盯清算
解锁窗口内，或团队地址充值 CEX 供应冲击 / 出货迹象 → 警惕解锁砸盘或拉高出货

2. OI、OI÷市值、大户多空比怎么读

指标 根据什么 怎么理解
OI 价涨且 OI 升 新仓在堆积，趋势靠杠杆推动，后续回撤时清算会更猛
OI 价涨且 OI 降 仓位在关，更像空头平仓/爆仓，而不是新多进场
OI 价跌且 OI 降 多头仓位被打掉，下跌由清算驱动
OI 价跌且 OI 升 空头在加仓，下跌可能还有延续
OI÷市值 比值偏低（如 < 0.1） 杠杆不拥挤，同样涨跌幅的清算风险相对小
OI÷市值 比值 ≥ 0.2 / ≥ 0.3 小盘高杠杆；同样 8% 波动更容易连环清算，结论更倾向「过热」
大户多空比 > 1（如 1.8） 持多大户数多于持空；若同时价涨+OI 升，大户拥挤做多，向下清算风险更大
大户多空比 < 1（如 0.7） 大户偏空；若同时价跌+OI 升，空头合力更强。比值接近 1 则多空大致均衡
组合 OI÷市值高 + 大户多空比很高 + 正费率 多头拥挤且杠杆大，一旦转跌优先按清多处理，而不是普通回调
组合 OI÷市值高 + 大户多空比很低 + 负费率 空头拥挤，价格拉升时更像轧空，而不是基本面驱动的慢牛

3. 合约净流入 / 现货净流入（交叉验证）

合约净流入看永续谁在主动成交；现货净流入看现货谁在主动成交。口径是主动买 − 主动卖（USD），不是链上充提。接入后用来验证上面的轧空 / 拉盘 / 清多是否扎实。

价格 合约净流入 现货净流入 更可能的含义 对现有结论的用法
涨 + + 现货+合约一起买，真拉盘 强化「主动拉盘追多」
涨 + − 合约在追，现货在出 → 高位出货 / 轧空末段 「轧空」时降置信度，警惕出货
涨 − + 现货买、合约减仓或空头平 → 偏轧空 更接近健康逼空，而非杠杆堆多
跌 − − 现货+合约一起卖，双杀砸盘 强化砸盘 / 解锁砸盘判断
跌 − + 合约清多，现货有人接 对应「多头清算」，下跌或接近尾声
跌 + − 现货出货，合约在抄底 / 开多 现货抛压仍在，反弹需谨慎
